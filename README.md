A one-line office joke, written by a program for the
[One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc)
competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one single-line joke about office life to `/output/entry.txt`.
The joke turns on a real office detail — the printer that only jams when it
matters most — and lands its laugh in the last few words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
